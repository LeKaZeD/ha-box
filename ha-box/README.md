# HA Box – Home Assistant App

![Supports aarch64 Architecture](https://img.shields.io/badge/aarch64-yes-green.svg)

Bridges the **haboxesp** ESP32 board with Home Assistant. Drives the E-Paper display, sensors, clock, weather, day/night mode, fan control, and exposes a RFLink-compatible TCP server for the CC1101 433 MHz module.

Requires a Raspberry Pi 4 or 5 running Home Assistant OS with the haboxesp board connected via UART.

See the **Documentation** tab for installation, configuration, and setup.
